Android native steps (NOT done in this zip: the Android project was not in the uploaded APK; untested)

1) Come-back notification (after 7 days away)
   npm i @capacitor/local-notifications
   npx cap sync android
   AndroidManifest.xml:  <uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
   The game code already schedules it (id 7001) when the plugin exists; it asks permission on first launch.
   This is a LOCAL scheduled notification. Real server push (Firebase) needs a backend and is a separate job.

2) Full screen / landscape
   MainActivity onCreate (after super.onCreate):
     WindowCompat.setDecorFitsSystemWindows(getWindow(), false);
     WindowInsetsControllerCompat c = WindowCompat.getInsetsController(getWindow(), getWindow().getDecorView());
     c.hide(WindowInsetsCompat.Type.systemBars());
     c.setSystemBarsBehavior(WindowInsetsControllerCompat.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE);
   Repeat the same in onWindowFocusChanged(boolean hasFocus) when hasFocus is true.
   AndroidManifest <activity>:  android:screenOrientation="sensorLandscape"   (landscape only; use "fullSensor" for both)
   styles.xml (API 28+): <item name="android:windowLayoutInDisplayCutoutMode">shortEdges</item>
   Note: heads-up notifications can still appear briefly over a full-screen game; Android does not let an app block them without Do Not Disturb access.
